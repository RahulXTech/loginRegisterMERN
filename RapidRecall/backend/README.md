# RapidRecall

RapidRecall is a full-stack MERN application built for technical interview preparation.

## Features

- JWT Authentication
- MCQ Quiz System
- Dashboard Analytics
- Leaderboard
- Bookmarks
- Daily Challenge
- Admin Panel
- Difficulty-based Questions
- Subject-wise Performance Tracking

## Tech Stack

Frontend:
- React.js
- Tailwind CSS
- Redux Toolkit

Backend:
- Node.js
- Express.js
- MongoDB
- JWT
- bcrypt
